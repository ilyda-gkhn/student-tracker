# Academic Zen – Öğrenci Takip Uygulaması
🔗 [Canlı demoyu görüntüle](https://ilyda-gkhn.github.io/student-tracker/)
Academic Zen; dersleri, sınavları ve haftalık çalışma programını tek bir arayüzden takip etmek için hazırlanmış tarayıcı tabanlı bir öğrenci planlama uygulamasıdır.

## Özellikler

- Ders ekleme, düzenleme, kopyalama ve silme
- Aktif ve tamamlanan dersleri ayırma
- Sınav tarihi ve notu ekleme
- Haftalık çalışma programı oluşturma
- Takvim üzerinden etkinlikleri görüntüleme
- Ders, sınav ve program kayıtlarında arama
- Tamamlanma durumunu ve ilerlemeyi gösterme
- Profil bilgilerini arayüz üzerinden düzenleme
- Mobil ekranlara uyumlu görünüm

## Kullanılan teknolojiler

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts ve Material Symbols

## Çalıştırma

Projeyi kullanmak için `index.html` dosyasını modern bir web tarayıcısında açın. Tailwind CSS, yazı tipi ve simgeler CDN üzerinden yüklendiği için internet bağlantısı gerekir.

## Mevcut sınırlamalar

- Uygulama yalnızca tarayıcı tarafında çalışır; bir backend veya veritabanı bulunmaz.
- Eklenen ve düzenlenen veriler sayfa yenilendiğinde korunmaz.
- Takvim ekranı Mayıs 2026 için hazırlanmış sabit bir görünüm kullanır.

## Geliştirme fikirleri

- Verileri `localStorage` ile tarayıcıda saklamak
- Dinamik aylık takvim eklemek
- Form doğrulamalarını geliştirmek
- Dosyaları HTML, CSS ve JavaScript olarak modüllere ayırmak
